# Scholar-Sync

Summary:
    Scholar-Sync is a scholarship discovery platform that connects students with relevant scholarship opportunities. It includes a Python backend for managing          scholarship data and a React frontend for user interaction.

Key Features:
    - Browse and search scholarships
    - Personalized recommendations based on user role and interests
    - Separate provider and student views
    - Simple API for scholarship data

Project Structure:
    - `backend/` - Python Flask backend and scholarship catalog logic
    - `database/` - JSON schema for database structure
    - `frontend/` - React app for the user interface
    
Notes:
    - The backend serves scholarship data and can be extended with real database support.
    - The frontend provides authentication pages, recommendation pages, and a chatbot interface.
    - Use the existing sample data or update the backend to add new scholarship entries.
